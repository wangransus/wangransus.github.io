# Ran Wang | Academic Homepage

This Jekyll/GitHub Pages site hosts the academic profile of Prof. Ran Wang at Shanghai University of Sport.

Live site: https://wangransus.github.io/

## Contents

- Profile, research focus, news, education, projects, awards, and team information
- Selected publications with cover images and downloadable PDFs
- Google Scholar citation badge powered by the `google-scholar-stats` branch

## Development

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.
